AI 에이전트를 체계적으로 만드는 체육관

ClawGym — 데이터 합성부터 학습까지, Claw 에이전트의 전주기를 하나로

미노 · 2026-05-01

"파일 정리해줘", "이 문서 편집해서 보고서 만들어줘", "저번 주 회의록에서 결정된 사항을 스프레드시트에 정리해줘".

이런 요청을 컴퓨터에 하면 AI가 직접 파일을 읽고, 코드를 실행하고, 결과물을 만들어낸다. 이런 걸 Claw 스타일 에이전트라고 부른다. ChatGPT의 "Claw" 기능이나 Claude의 "Computer Use"가 대표적이다.

문제는 이런 에이전트를 체계적으로 만들고 평가하는 방법이 없었다는 거다. 2026년 中国人民대학과 IQuest Research 연구진이 이 빈자리를 ClawGym이라는 프레임워크로 채웠다.

"왜 이게 어려웠을까?"

생각보다 어렵다. 세 가지 이유가 있다:

① 어떤 태스크를 줘야 할지 모른다. 사람은 각자 다른 직업과 일상을 가지고 있다. 개발자한테 "파일 정리해줘"라고 하는 것과 변호사한테 "파일 정리해줘"라고 하는 건 완전히 다른 일이다. 이 다양성을 대표하는 태스크를 정의하는 게 어렵다.

② 긴 작업을 평가하기 어렵다. 파일을 읽고, 코드를 실행하고, 결과를 저장하고, 다시 확인하는 식의 긴 시퀀스를 자동으로 평가하는 건 난제다. "최종 결과물이 맞아?" 하고 묻는 걸로는 부족하다.

③ 현실적인 환경이 필요하다. 에이전트가 일하려면 실제 파일과 폴더가 있는 작업 공간이 필요한데, 이걸 자동으로 만들어주는 시스템이 없었다.

"체육관 같은 프레임워크"

ClawGym은 이름 그대로 에이전트를 위한 "체육관"이다. 운동선수가 체계적으로 훈련하고 성장하는 것처럼, AI 에이전트도 데이터 합성 → 학습 → 평가의 전주기를 거치게 된다.

세 가지 모듈로 구성된다:

① ClawGym-SynData — 문제은행 만들기 (13,500개)

에이전트에게 줄 태스크를 대규모로 합성하는 모듈이다. 재미있는 건 이걸 두 가지 방향에서 동시에 만든다는 점이다.

Top-Down(위에서 아래로): 특정 직업과 페르소나를 먼저 정의하고, 그 사람이 일상에서 할 법한 지시문을 만든다. "데이터 분석가가 주간 리포트를 자동 생성하는" 식으로. 다양성을 확보하는 접근이다.

Bottom-Up(아래에서 위로): 구체적인 실행 능력(스킬)을 먼저 정의하고, 여러 스킬을 조합해서 다단계 워크플로우를 만든다. "파일 읽기 + 데이터 정리 + 차트 생성"을 합치는 식으로. 실행 가능성을 보장하는 접근이다.

② ClawGym-Agents — 에이전트 훈련시키기

합성된 태스크를 바탕으로 에이전트를 학습시킨다. 두 단계를 거친다:

SFT(지도 미세조정): 에이전트가 태스크를 수행하는 과정을 대량으로 수집하고, 그 중 잘한 것들만 골라서 모델을 학습시킨다. 마치 우수 직원의 업무 노하우를 교재로 만드는 것과 같다.

RL(강화학습): 샌드박스 환경에서 에이전트가 여러 번 시도하게 하고, 성공하면 보상을 주어 더 나은 전략을 스스로 찾게 한다. 각 태스크별로 독립된 샌드박스를 병렬로 실행해서 효율을 극대화한다.

③ ClawGym-Bench — 실력 평가하기 (200개)

학습된 에이전트를 공정하게 평가하는 벤치마크다. 6개 카테고리에 걸쳐 200개의 태스크로 구성된다.

재미있는 건 평가 자체도 엄격하다는 점이다. 너무 쉬운 문제나 너무 어려운 문제는 난이도 필터링으로 걸러내고, LLM 보조 인간 검토까지 거쳐서 학습 데이터와 겹치는 문제를 철저히 배제한다.

"소형 모델이 대형 모델을 이겼다"

가장 인상적인 결과다. ClawGym으로 학습시킨 결과:

  • Qwen3-8B (소형): 기존 대형 모델의 기준 성능을 상회. PinchBench에서 +38.9%, ClawGym-Bench에서 +43.5%
  • Qwen3-30B-A3B (대형): 이미 높은 성능에서도 +26%~54.7% 추가 향상

이건 단순히 "데이터를 많이 넣어서"가 아니다. 페르소나 기반 다양한 시나리오 + 스킬 기반 실행 가능한 워크플로우라는 고품질 데이터가 핵심이다.

소형 모델이 대형 모델보다 성능이 좋아졌다는 건, Claw 에이전트 분야에서는 데이터 품질이 모델 크기보다 중요하다는 강력한 증거다.

핵심 시사점

1. 합성 데이터만으로도 강력한 에이전트가 가능하다. 사람이 직접 만든 데이터 없이, 시스템이 자동 생성한 13,500개 태스크만으로 소형 모델이 대형 모델을 뛰어넘었다. 이건 에이전트 연구의 진입 장벽을 크게 낮추는 결과다.

2. 데이터 품질이 모델 스케일보다 중요하다. 듀얼 라우트(페르소나 + 스킬)로 만든 데이터의 품질이 높을수록, 작은 모델도 큰 모델을 이긴다. 더 큰 모델을 만드는 것보다 더 좋은 데이터를 만드는 것이 효율적일 수 있다.

3. 평가의 신뢰성도 시스템적으로 보장해야 한다. 벤치마크에 학습 데이터가 섞여 있으면 공정한 평가가 불가능하다. ClawGym은 난이도 필터링, LLM 보조 인간 검토, 학습셋 중복 배제 등 평가 자체의 신뢰성을 시스템적으로 보장하는 방법론을 제시했다.
